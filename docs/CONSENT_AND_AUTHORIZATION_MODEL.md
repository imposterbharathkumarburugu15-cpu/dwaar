# Purpose-Bound Consent & Authorization Model

## Model Principles
In compliance with the Digital Personal Data Protection (DPDP) Act, PRAMANA enforces strict purpose-bound consent prior to querying external registries.

1. **Purpose Specification**: Every consent record specifies the explicit verification purpose.
2. **Time Delimitation**: Consent carries a mandatory `valid_until` timestamp.
3. **Revocability**: Institutions or applicants can revoke consent at any time.
4. **Audit Immutability**: All consent grants and revocations generate cryptographically chained audit events.
