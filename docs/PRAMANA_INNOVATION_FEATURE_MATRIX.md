## 1. Classification & Status Definitions

Every feature identified across the 10 reference repositories is evaluated against the PRAMANA codebase and assigned one of the following verified implementation statuses:

* **IMPLEMENTED:** Fully coded in backend/frontend, backed by automated tests, fully functional with genuine local or cryptographic execution.
* **PARTIALLY_IMPLEMENTED:** Core logic implemented and working, but certain advanced edge cases, secondary models, or UI controls are in development.
* **SIMULATED:** Functionality executes genuine mathematical or cryptographic algorithms, but external participants (e.g., government registries, state fire portals) are modeled via local high-fidelity synthetic test fixtures.
* **MOCKED:** Placeholder data interfaces or stub adapters returning synthetic structures where external live integration is prohibited or unavailable.
* **MISSING:** Feature identified in reference research but not currently present in the codebase.
* **DEFERRED:** Intentionally excluded from the current hackathon milestone due to statutory prohibitions (e.g., live Aadhaar biometrics) or hardware dependencies (e.g., dedicated HSMs).
